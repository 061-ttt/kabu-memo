# 設計プロンプト

> 音声入力の指示を、そのまま実装に使える仕様へ組み直したもの。このプロンプトで実装した。

## 役割

あなたはモバイルWebのシニアフルスタックエンジニア兼プロダクトデザイナー。設計・実装・テスト・公開までを一人で完遂する。完了の定義は「実ブラウザで操作する自動テストが全件合格していること」。

## 0. 入力の解釈（音声入力の補正）

| 指示 | 解釈 |
|---|---|
| 参考の録画（話題株ノート） | 日付ごとの銘柄ノート。見出し／材料と反応／素直に受け取れない点／強弱マーク／日足チャート／PER・PBR・ROE・時価総額・出来高。構造は参考にし、見た目と名前は複製しない |
| 開いた瞬間メモ | 最初の描画でメモ欄が表示され、入力できる。JS読み込み・認証確認・通信を一切待たない。書きかけは打鍵ごとに端末へ保存 |
| フリックでステータス管理 | タスクカードを右に払うと次の状態、左に払うと前の状態（未着手→進行中→完了）。未着手で左に払うと削除（取り消し可） |
| Liquid Glass UI・白ベース | 半透明＋背景ぼかし＋縁の鏡面ハイライト＋（対応ブラウザで）屈折。白地に淡い色の光を置き、ガラス感を出す |
| アニメーションをふんだんに | 画面遷移、リスト出現、スワイプのばね、数値カウント、チャート描画、タブの液体インジケーター、押下の弾性。`prefers-reduced-motion` では止める |
| 全画面スケルトン | 各画面の初回データ取得中は、実レイアウトと同形のスケルトンが画面全体を占める。メモ欄だけは常に操作可能 |
| 余計なキャッチコピー不要 | ヒーロー文・説明文・空状態の煽り文を置かない。表示する文字は機能名と内容だけ |
| バックエンドは基本Cloudflare | Workers（静的配信＋API）、D1、Workers AI |
| ログインはGoogleのみ | OAuth 2.0 認可コード＋PKCE。他のログイン手段は作らない |
| 公開まで | GitHub公開リポジトリ、CI、Cloudflareへの自動デプロイ経路 |

## 1. 機能要件

1. **メモ**：即時入力・保存（Enter＝改行、⌘/Ctrl+Enter または保存ボタン＝保存）。本文から銘柄コード（`5333`、`285A` 形式）を自動抽出してチップ表示。日付ごとに一覧。左フリックで削除（取り消し可）。
2. **AI分析（Workers AI）**：メモ1件から、言及銘柄ごとに「材料と反応」「素直に受け取れない点」「強／弱／なし」「テーマ」、および次にやるべきタスク案を構造化JSONで生成。結果はメモに保存し、銘柄ノートとタスクへ取り込める。
3. **銘柄ノート**：日付ごとの銘柄カード一覧（強・弱フィルタ、検索）。詳細シートに見出し・材料と反応・素直に受け取れない点・日足ローソク足（1M/3M/6M）・指標（PER・PBR・ROE・時価総額・出来高）・関連メモ・株探へのリンク。
4. **タスク**：追加、フリックで状態遷移、状態別の件数表示。
5. **同期**：未ログインでもメモは端末に保存。ログイン後に自動でサーバーへ同期（楽観的更新＋送信キュー、ID衝突は他ユーザーのデータを上書きしない）。
6. **日付移動**：`‹ 2026年11月18日(水) ›`。日付はJST基準。

## 2. 非機能要件

- モバイルファースト（390×844基準）、横スクロールを出さない、セーフエリア対応。
- 初回表示の速さを最優先：メモ欄は静的HTML＋インラインの数百バイトのスクリプトで動かす。Webフォントを使わない。Service Workerでアプリ外殻をキャッシュ。
- セキュリティ：HttpOnly＋Secure＋SameSite=Laxのセッションクッキー、セッションIDはハッシュで保存、変更系APIはOriginを検証、全SQLはプレースホルダ、AIの利用回数を1日単位で制限、AI出力はスキーマ検証してから保存。
- アクセシビリティ：ボタンに名前、フォーカス可視、スワイプ以外の操作手段（ボタン）も用意。

## 3. 技術選定の条件

- 選んだ技術すべてに理由を書く（なぜそれか、何と比べたか）。
- 外部の鍵（Cloudflare・Google）が必要な箇所は、模擬サーバーでテストし、本番では環境変数で切り替える。本番コードに認証の抜け道を作らない。

## 4. 受け入れテスト（すべて実ブラウザで自動実行）

1. アプリのJSを読み込ませなくても、メモ欄が表示され入力でき、再読み込みで書きかけが戻る。
2. 未ログインでメモを保存→一覧に出る→再読み込み後も残る。
3. 模擬GoogleでOAuthログイン（state・PKCE検証込み）→端末のメモがサーバーへ同期される。
4. データ取得を遅延させると全画面スケルトンが出て、取得後に消える。
5. タスクを右フリック2回で完了、左フリックで戻る。状態がサーバーに保存される。
6. AI分析で「材料と反応」「素直に受け取れない点」が表示され、銘柄ノートとタスクへ取り込める。
7. 銘柄を追加→詳細にチャートと指標が出る。強・弱フィルタと検索が効く。
8. 日付移動で一覧が切り替わる。
9. ログアウトできる。
10. 未認証のAPIは401、他オリジンからの変更は403、他人のIDでの上書きは不可。
11. `prefers-reduced-motion` でアニメーションが止まる。横スクロールが出ない。

## 6. 進め方

要件→データモデル→API→画面→テスト→公開の順。各段階で動くものを確認し、テストが落ちたら原因を直してから進む。できないこと（鍵が必要な本番デプロイ等）は隠さず、残り手順を最短で示す。
