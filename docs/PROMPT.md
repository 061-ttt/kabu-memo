# 設計プロンプト（相場帖）

> 参考の画面録画（話題株の備忘録アプリ）を分析して組み立てたプロンプト。第1段でこの仕様の画面を作り、第2段で株価の自動取得とサーバー保存を足した。
> 以前の「株メモ」の設計プロンプトは git の履歴（コミット b28b1f0）に残っている。

## 役割

日本株の個人投資家向けツールを専門とする、シニアのフロントエンドエンジニア兼プロダクトデザイナー。

## 目的

参考の録画にある「話題株の備忘録アプリ」と同じ情報設計・使い心地のWebアプリを、モバイルファーストで作る。
名称・キャラ・ロゴは参考元を使わずオリジナルにする。アプリ名：相場帖

## 参考画面から読み取った仕様（すべて再現）

1. ヘッダー：アプリ名／‹ 日付 ›（日ごとにデータ切替）／文字サイズ A− 100% A+／効果音／ダークモード／時計
2. タブ：全般・昨晩の米国株・本日の日本株（日ごとのメモ）／話題株（件数）／ツヨ・ヨワ（強＋弱の件数）
3. 話題株一覧：すべて・強・弱の件数チップ、銘柄名・コード・テーマ検索、＋銘柄。
   行＝銘柄名＋コード、強弱マーク、テーマタグ、見出し、推移スパークライン、終値、前日比ピル
4. 銘柄詳細
   - 銘柄名（明朝・金）＋コード＋印、テーマ、見出し（金の左罫）、「→ ※一言の結論」
   - 「材料と反応」カード、「※ 素直に受け取れない点」カード（四隅のカギ装飾）、出所リンク
   - 終値と前日比、日足ローソク足＋出来高（1ヶ月/3ヶ月/4ヶ月）、現在値の点線と価格タグ
   - 指標6枚：PER(実績)・PER(予想)・PBR・ROE・時価総額・出来高、「終値ベース」表記
   - フッター：← 一覧／株探↗／この銘柄を消す／n/N ‹ ›
5. 世界観：和紙のクリーム地＋青海波の地紋＋金、上昇=赤・下落=青（日本式）、画面下をドット絵キャラが歩く

## モバイルファースト（375px基準）

- 一覧はカード：①名前・コード・印｜終値・前日比 ②見出し ③テーマ＋スパークライン
- 詳細は1カラム：価格→チャート→指標→見出し→結論→材料と反応→素直に受け取れない点→出所
- 詳細は左右スワイプで前後の銘柄へ、下部に固定バー
- タブは横スクロール、タップ領域44px以上、safe-area対応
- 900px以上は参考と同じ2カラム＋テーブル

## 機能

- 銘柄の追加・編集・削除（ボトムシート、削除は確認つき）
- 「AIで下書き」：見出しと材料から、テーマ・一言・素直に受け取れない点・強弱を提案（懐疑的視点を必ず含める）
- 価格：終値・指標は手入力、日足はCSV貼り付け。データがない銘柄は「サンプル」表示の合成チャートにし、実データと混同させない
- 保存：端末間同期ストア、使えなければ端末内。JSON書き出し／読み込み
- キャラをタップすると、表示中の銘柄の「素直に受け取れない点」を吹き出しで話す

## データモデル

- Entry {date, code, name, mark, theme, headline, takeaway, material, caveat, source, close, change, changePct, metrics, ohlc}
- Note {date, tab, body}

## 技術・品質

- 単一画面、フレームワーク不使用
- ライト/ダーク、prefers-reduced-motion、キーボード操作（←→・Esc）
- 初回は2026/11/18の話題株をサンプル表示（空画面にしない）
- 投資助言ではない旨を明記

## 検証

375pxと1280pxで表示確認、コンソールエラー0、チップ件数と一覧件数の一致

## 第2段：株価の自動取得（追加の指示）

- 株価・指標は **J-Quants API V2**（JPX総研・個人向け）から取る。APIキーはサーバーだけが持つ
- 画面と API を同じ Worker に置く（Cloudflare Workers＋D1）。ログインは Google のみ。`ALLOWED_EMAILS` で本人だけに絞れること（J-Quants は個人の私的利用が条件）
- コードを入れたら、銘柄名・終値・前日比・日足・PER/PBR/ROE/時価総額を自動で入れる
- 取得した日足と指標は D1 に貯め、同じ取得を繰り返さない。当日分は大引け後（16:30ごろ）の配信まで前日の値を「配信待ち」と明示して出す
- 取れないとき（キー未設定・プラン外・回数制限）は理由を画面に出し、手入力の値で表示を続ける
- 未ログインでも端末保存で全機能（株価取得・AI・同期以外）が動き、ログインした時点で端末のデータをサーバーへ送る
- AI は Workers AI（文章の下書き＋スクショ読み取り）。1日の回数上限つき
- 受け入れ：実ブラウザの自動テスト（模擬 Google・模擬 J-Quants・模擬 AI）が全件合格
